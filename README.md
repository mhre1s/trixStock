TrixStockSistema de Gestão de Ativos & Integração Estratégica com ERP RouterboxEste projeto foi desenvolvido para a Trixnet com o objetivo de centralizar o controle de equipamentos de rede e automatizar a sincronização com o ERP oficial da empresa.🔗 Links ÚteisAplicação Online: Acesse o TrixStock aquiDocumentação da API: Disponível sob consulta🔑 Acesso para Recrutadores (Sandbox)Para que você possa testar as funcionalidades sem expor dados sensíveis, utilize as credenciais abaixo:UsuárioSenhatesterecrutador@trixnet.com.br12345678⚠️ Nota: Este ambiente está conectado ao Endpoint de Homologação do Routerbox. Nenhum dado inserido aqui afeta a produção real.🚀 Visão Geral do SistemaO TrixStock elimina o retrabalho e garante a integridade dos dados através de:Sincronização em Duas Etapas: O item é persistido localmente e, em seguida, enviado ao ERP. O ID de retorno (rbx_id) é vinculado ao registro para futuras consultas.Tratamento de Concorrência: Lógica de backend para evitar duplicidade de MAC Adress e Números de Série.Dashboard Inteligente: Filtros por status (Novo, Usado, Defeito) e categorias de ativos.🛠️ Stack TecnológicaCamadaTecnologiaBackendNode.js + Express.jsFrontendReact + Tailwind CSSBanco de DadosPostgreSQL + Sequelize ORMIntegraçãoAxios (API REST)InfraestruturaDocker + Docker ComposeProdutividaden8n (Automações) + Vibe Coding📸 Demonstração(Arraste seus prints aqui para as seções abaixo)Tela de Cadastro com IntegraçãoListagem de Equipamentos⚙️ Como Executar o Projeto (Local)Clone o repositório:Bashgit clone https://github.com/mhre1s/trixstock.git
